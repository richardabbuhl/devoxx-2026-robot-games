## Venue Photos

The 14 original photos in `assets/venue-photos/` are supplied by the references page as visual references for materials, lighting, and the venue. That page describes them as published under a copyleft licence and links to the [Devoxx Belgium Flickr archive](https://www.flickr.com/photos/bejug/albums/). Check each photo's original Flickr page for its specific creator credit and licence before redistributing it in a published game.

The competition brief asks entrants to build their own game and not ship the Robot Lab demo as the game itself. These files are reference materials, not a game implementation.
