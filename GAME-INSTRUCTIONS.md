# Devoxx 2026 Robot Games

Source: https://game.devoxx.be/game.html

## The brief

Build a playable game set in Kinepolis Antwerp in which all three robots appear
and matter. Any engine, language, stack, dimension, or genre is allowed. The
game should present an original idea, robots that move like machines with
weight, and a recognisable venue with rules worth replaying.

Generative AI may be used for modelling, environment creation, code, and audio.
Document the tools used, prompts, iterations, and any problems fixed by hand in
the repository.

The game must:

- Give Voxxy, Droid, and Biggy a reason to exist and a distinct role.
- Make the Kinepolis exhibition hall, auditoriums, corridors, and connecting
  staircase recognisable. One or both building levels may be used.
- Be playable by someone unfamiliar with the game: they must be able to start,
  understand the goal, and finish a round.
- Run from the repository, with a README explaining how to clone and play it.
- Include an MIT `LICENSE` file.

## The robots

### Voxxy

The orange companion: light, curious, and quick on its feet. Voxxy is the robot
players will want to control.

### Droid

Tall, weathered, and deliberate, with exposed joints and scuffed panels. Droid
has been in the building a long time.

### Biggy

Short legs and heavy armour. Biggy is slow to start and hard to stop once it is
moving.

## The venue

The game takes place at Kinepolis Antwerp, where Devoxx Belgium is held. The
venue reference covers auditoriums 1 through 14, the corridor between them, the
foyer, and the grand staircase from the exhibition floor. The building has two
levels: the cinema level and the exhibition hall on the ground floor, including
the entrance, reception, and BOF rooms.

It is not necessary to model every room, but the place must be recognisable to
the developers who attend Devoxx. The floor plan and venue photographs are
available from the reference page.

## How the game is judged

The total score is 100 points:

- **Originality: 40 points.** Show an unexpected genre, mechanic, or reading of
  the brief. Originality is the largest part of the score.
- **Realism: 15 points.** Robots should move with mass, momentum, floor contact,
  and lighting that belongs in a cinema.
- **Playability: 10 points.** Provide clear goals, understandable controls,
  honest feedback, and a reason to play another round.
- **All three robots: 10 points.** Each robot must do something only it can do;
  simple reskins score poorly.
- **Sense of place: 5 points.** The game should clearly feel like Kinepolis
  before the player is told where it is.
- **GenAI craft: 5 points.** Document how tools were directed and what was
  corrected manually.

## Submission

Submit a public GitHub repository by **30 September 2026 at 23:59 CEST**. The
latest submission before the deadline is judged.

The repository must be MIT licensed and its README must explain how to run the
game. A hosted playable build may also be submitted. Include the technologies
and generative AI tools used, with enough detail to earn the GenAI craft points.

Submit through the form on the [game page](https://game.devoxx.be/game.html#submit).
Questions can be sent to [games@devoxx.com](mailto:games@devoxx.com).
